# Security policy

Zagkit is pre release software and currently has no supported runtime. Security
issues in repository automation, specifications, or future implementation
should be reported privately through the Sylor Labs GitHub organization contact
or GitHub private vulnerability reporting when it is enabled for this
repository.

Please include the affected revision, platform, backend, reproduction, impact,
and whether the issue crosses a process, GPU, accessibility, input, font, or
package boundary. Do not include secrets or destructive proof when a bounded
reproduction is sufficient.

No version is currently eligible for security support. A beta or stable release
will replace this paragraph with its exact support window and response policy.
